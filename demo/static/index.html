DQN model and training

The network receives six grid layers, ten features for each of the 18 arms, and four context values: wind, remaining budget and time.

The map passes through two convolution layers. Arm features pass through a dense layer. These are combined to produce 163 Q-values—one per complete allocation. Invalid allocations are masked before choosing the highest value.

How it learned

    
    
      
  1. Try feasible allocations in training episodes, using epsilon-greedy exploration.
    2. 
      
  2. Store the observation, action, reward and next observation in replay memory.
    3. 
      
  3. Sample past experiences and update the network towards a masked Bellman target.
    4. 
      
  4. Periodically copy online weights to the target network; evaluate on separate validation worlds.
    5. 
    

    
target = reward + gamma × best feasible next Q

    
At the episode boundary, the target is just the reward. New burning, clearing,
       and settlement damage are penalized. Materials and capacity are hard constraints.

    
This demo uses saved weights. Playback does not train the network.

    
Firebreaks affect neighbouring arms, so this is a spatially coupled
       CRMAB extension. It does not assume independent arms or inherit indexability guarantees.
