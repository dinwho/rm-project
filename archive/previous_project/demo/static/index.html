CRMAB mathematical model

At interval t, the state contains fuel, active and prior fire, firebreak cells, wind, resources, and time. The policy chooses an eligible cell or waits; then the shared fire field advances once.

Xt+1 = F(Xt, at, W, Ut)
rt = −(Bt + λcCt)/|V| − λsDt/max(1, |S|)
at ∈ eligible cells ∪ {wait}

Fire spread couples neighboring cells, so independent-arm factorization and classical indexability guarantees do not apply. This is a mathematical CRMAB extension, not the Firehose/Cell2Fire simulator.

Masked DQN policy

The network receives six grid layers, ten features per candidate cell, and four context values. It produces one Q-value per cell plus wait; infeasible actions are masked before selection.

How it learned

    
    
      
  1. Try feasible allocations in training episodes, using epsilon-greedy exploration.

  3. Sample past experiences and update the network towards a masked Bellman target.

  4. Periodically copy online weights to the target network; evaluate on separate validation worlds.

target = reward + gamma × best feasible next Q

    
At the episode boundary, the target is just the reward. New burning and clearing
       are penalized. The construction limit is one cell per fire interval.

    
This demo uses saved weights. Playback does not train the network.

    
Firebreaks affect neighbouring arms, so this is a spatially coupled
       CRMAB extension. It does not assume independent arms or inherit indexability guarantees.
